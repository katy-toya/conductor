# Conductor

`Conductor` は、[ZMK Firmware](https://zmk.dev/) をベースにしたカスタムキーボードファームウェア設定です。

## 主な構成

- **ボード**: `seeeduino_xiao_ble`
- **シールド**:
  - `monokey_R` + `rgbled_adapter`
  - `monokey_L` + `rgbled_adapter`
  - `settings_reset`

---

## ファームウェアのビルドと書き込み手順

### 1. GitHub Actions でビルドする

1. このリポジトリの **Actions** タブを開く
2. 左サイドバーから **Build** ワークフローを選択
3. **Run workflow** ボタンをクリックしてビルドを実行
   - または、`config/` 以下のファイルを変更して push すると自動でビルドが走ります

### 2. ファームウェアファイルをダウンロードする

1. ビルドが完了したら **Actions** タブを開く
2. 対象のワークフロー実行をクリック
3. ページ下部の **Artifacts** セクションから `firmware` をダウンロード
4. ZIP を展開すると以下の `.uf2` ファイルが含まれています:

| ファイル名 | 書き込み先 |
| :--- | :--- |
| `seeeduino_xiao_ble_monokey_R_rgbled_adapter-zmk.uf2` | 右手側 (monokey_R) |
| `seeeduino_xiao_ble_monokey_L_rgbled_adapter-zmk.uf2` | 左手側 (monokey_L) |
| `seeeduino_xiao_ble_settings_reset-zmk.uf2` | 設定リセット用 |

### 3. キーボードにファームウェアを書き込む

Seeed Studio XIAO BLE はブートローダーモードにすると USB マスストレージとして認識されます。

#### ブートローダーモードへの入り方

1. キーボードを PC に USB で接続する
2. XIAO BLE 基板上の **リセットボタンをすばやく 2 回押す**（ダブルクリック）
3. PC に `XIAO-SENSE` または `XIAO BLE` という名前のドライブが表示される

> **ヒント**: ダブルクリックがうまくいかない場合は、ZMK の `&bootloader` キーコード（Bluetooth レイヤー）を使ってブートローダーに入ることもできます。

#### `.uf2` ファイルの書き込み

1. ブートローダーモードで表示されたドライブに `.uf2` ファイルをコピー（ドラッグ＆ドロップ）
2. コピーが完了するとキーボードが自動的に再起動し、新しいファームウェアが適用される

#### 書き込み順序（分割キーボードの場合）

右手側・左手側を **どちらから書き込んでも構いません**。ただし設定リセットが必要な場合は以下の順で行います:

1. `settings_reset.uf2` を **両方の半体** に書き込む（Bluetooth ペアリング情報をクリア）
2. 通常のファームウェア (`monokey_R`, `monokey_L`) を書き込む
