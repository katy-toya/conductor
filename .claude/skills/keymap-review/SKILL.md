name: keymap-review
description: キーマップのレビュー。コンボ競合、レイヤー設計の問題、
  ホールドタップの設定ミスを検出する必要がある場合に使用。
  「キーマップを確認して」「レイヤーを見直して」などの指示で自動発動。
allowed-tools: Read, Grep, Glob
---
config/monokey.keymap を読み込み、以下の観点でレビューしてください：

1. **コンボ競合**: 同じキーポジションを複数コンボが使っていないか
2. **レイヤー透過**: &trans の連鎖が意図通りに機能するか（特に &to で固定したレイヤーの透過先）
3. **ホールドタップ**: quick-tap-ms = 175 / flavor = "balanced" がタイピングスタイルに適切か
4. **キー数**: 各レイヤーが40キー（最終行: 左6+右4の変則）になっているか
5. **アクセシビリティ**: 頻用キーが使いにくい位置にないか

問題点は重要度（high/medium/low）付きで列挙し、修正案を提示してください。
